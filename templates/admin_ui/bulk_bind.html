What the file needs

An Ark_ID column plus one column per element. Every other column becomes an element with that name — there is no fixed list.

Ark_ID,URL,PID,LOCAL_ID
61220/utsc0,https://example.org/0,islandora:0,obj-0
61220/utsc1/page1,https://example.org/1/p1,,

An Ark_ID may carry a qualifier such as /page1 or /page1.image.png. An empty cell leaves any existing value alone. The whole file is checked before anything is written, so a bad row cannot half-apply.
